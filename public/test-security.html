🔐 Security Test: Admin Authorization

Testing server-side authorization to prevent non-admin users from performing admin actions

🔑 Login Get Token
❌ Test 1: No Token 401 Expected
Attempt to update a record WITHOUT an authentication token. This should be rejected with 401 Unauthorized.
❌ Test 2: Fake Token 401 Expected
Attempt to update a record WITH a fake/invalid token. This should be rejected with 401 Unauthorized.
❌ Test 3: User Token (Non-Admin) 403 Expected
Attempt to update a record WITH a valid token but WITHOUT admin privileges. This should be rejected with 403 Forbidden.
✅ Test 4: Admin Token 200 Expected
Attempt to update a record WITH a valid admin token. This should succeed with 200 OK.
✅ Test 5: Delete with Admin Token 200 Expected
Attempt to delete a record WITH a valid admin token. This should succeed with 200 OK.
🌐 Test 6: Public GET (No Auth) 200 Expected
GET records WITHOUT authentication (public endpoint). This should work for everyone.

📋 cURL Commands for Testing 
# 1. Login as Admin
curl -X POST http://localhost:3000/login \
  -H "Content-Type: application/json" \
  -d '{"username":"admin","password":"admin123"}'

# 2. Login as User
curl -X POST http://localhost:3000/login \
  -H "Content-Type: application/json" \
  -d '{"username":"user","password":"user123"}'

# 3. Test 1: No Token (Should return 401)
curl -X PUT http://localhost:3000/api/records/1 \
  -H "Content-Type: application/json" \
  -d '{"status":"Resolved"}'

# 4. Test 2: Fake Token (Should return 401)
curl -X PUT http://localhost:3000/api/records/1 \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer fake_token_123" \
  -d '{"status":"Resolved"}'

# 5. Test 3: User Token (Should return 403)
curl -X PUT http://localhost:3000/api/records/1 \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer USER_TOKEN" \
  -d '{"status":"Resolved"}'

# 6. Test 4: Admin Token (Should return 200)
curl -X PUT http://localhost:3000/api/records/1 \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer ADMIN_TOKEN" \
  -d '{"status":"Resolved","cleaner":"Admin Test"}'

# 7. Test 5: Admin Delete (Should return 200)
curl -X DELETE http://localhost:3000/api/records/1 \
  -H "Authorization: Bearer ADMIN_TOKEN"

# 8. Test 6: Public GET (Should return 200)
curl -X GET http://localhost:3000/api/records

💡 Replace ADMIN_TOKEN and USER_TOKEN with actual tokens from login responses.
